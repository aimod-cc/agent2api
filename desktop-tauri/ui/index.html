登录 / 添加 WorkBuddy 账号

账号版本

国内版走 copilot.tencent.com，国际版走 www.workbuddy.ai，两版账号可同时保存、按账号自动路由。

登录方式

系统浏览器可复用你已有的登录态（国际版推荐）；内嵌窗口与你日常浏览器隔离，更干净。

推荐：网页登录

打开官方 WorkBuddy 登录页，完成登录后自动加入账号列表（排在转发顺序最后，不会抢占首选账号）。账号昵称取自上游，无需手动填写。

将打开内嵌窗口，登录完成后自动加入账号列表；关掉此窗口即取消等待

备用：粘贴登录态 JSON

如果当前环境无法打开登录窗口，也可以把已有的 accessToken/refreshToken JSON 粘进来直接启用。

账号设置

转发路由

优先级是转发顺序，数值越小越先用。每个账号的优先级必须唯一——多个账号并列时「谁先用」会失去意义，因此保存时会拒绝已被占用的数值。调整顺序也可以直接在账号列表里用「↑ / ↓」与相邻账号交换。

出网代理

默认无代理（直连上游）。需要经代理访问时可选择 Clash Verge 里的出口；端口由 Clash Verge 管理，这里每次实时读取。
